## 서비스 개요

차량 IVI(인포테인먼트) 화면의 **"도착 모드" 주차 도우미**. 목적지를 설정하면 도착 시점의 주차장 혼잡을 예측해 보여주고,
도착 10분 전 음성으로 대체 주차장을 제안해 경유지로 넣어주며, P단 변속 시 주차 위치를 저장(층·구역은 음성으로 입력)해
폰으로 보내고, 다음 시동 때 주차 시간/무료 시간 요약과 다음 목적지 바로가기를 보여준다.

- 입력 수단: 음성(주) + 카드 터치(보조). 화면 하단 "듣고 있어요 / 말로 답하거나 카드를 눌러주세요".
- 클라이언트: 차량 IVI 앱. "폰으로 보냈어요" → 사용자 폰(FCM 푸시로 추정)으로 주차 위치 전송.

## 사용자 흐름

① 주행 중 대기 → ② 도착 10분 전 주차 브리핑 → ③ 경유지 추가 → ④-1 P단 주차 위치 저장·층/구역 묻기 → ④-2 저장 완료 → ⑤ 다음 시동 주차 요약

### ① 주행 중 대기 (`01_대기`)
"목적지를 설정하면 도착 모드가 켜지고, 내비 옆에서 조용히 대기"

- 헤더: `도착 모드` 라벨, 목적지명 `더현대 서울`, `도착까지 18분 · 12.4km`
- 예측 섹션 제목: `도착할 즈음, 주차장은 이럴 것 같아요`
- 예측 카드:
  - 주차장명 `더현대 서울 주차장` + 혼잡도 칩 `혼잡 예상`
  - `도착 시간대 만차율 95%`
  - 시간대별 만차율 막대그래프(30분 간격, 도착 시각 강조): `13:30 58%`, `14:00 80%`, `도착 95%`, `14:30 90%`, `15:00 82%`
- 하단 힌트: `근처에 더 여유 있는 주차장 2곳` / `도착 10분 전에 말로 알려드릴게요`
- 데이터 항목: 목적지(이름, 좌표), 남은 시간(분), 남은 거리(km), 목적지 주차장, 시간대별 예측 만차율(%), 혼잡도 등급,
  주변 대체 주차장 수

### ② 도착 10분 전 주차 브리핑 (`02_주차_브리핑`)
음성: "건물 주차장은 뒷편 입구, 300m 옆 공영주차장이 더 넓어요. 그쪽으로 갈까요?"

- 헤드라인: `더 편한 주차장을 찾아봤어요` / `도착 전에 정해두면 바로 길을 바꿔드릴게요`
- 주차장 카드 2장(`parking_card`):
  1. `여의도 공영주차장` [추천] — `300m · 실내 · 더 넓어요` — `여유 · 2시간 무료`
  2. `더현대 서울 주차장` [목적지] — `입구: 건물 뒷편 골목` — `혼잡 · 10분당 1,000원`
- 지도 마커: `추천 · 여의도 공영주차장`, `건물 주차장 · 뒷편 입구`
- 데이터 항목: 추천 후보 목록(주차장, 역할 = 추천/목적지, 목적지로부터 거리 m, 실내/실외, 추천 사유 문구,
  혼잡도 등급(여유/혼잡), 무료 시간, 요금 단위(분당 원), 입구 안내 문구), 사용자의 선택(수락/거절)

### ③ 경유지 추가 (`03_경유지_추가`)
"'응' 한마디로 공영주차장이 내비 경유지에 들어감"

- 체크 아이콘, `여의도 공영주차장을 경유지로 넣었어요`, `현재 위치로부터 300m`, 버튼(`ivi_basic_button`, 취소/확인류로 추정)
- 지도 마커: `경유지 · 여의도 공영주차장`
- 데이터 항목: 선택된 주차장, 현재 위치로부터 거리

### ④-1 P단 주차 위치 저장 · 층/구역 묻기 (`04_주차_기록`)
"기어 P → 위치 자동 저장 → '몇 층 어디에 세우셨어요?' 음성으로 물어봄"

- 상태 카드: [P] `여의도 공영주차장` / `14:20 주차 · 위치 저장됨`
- 질문: `몇 층 어디에 세우셨어요?` / `말해주시면 위치에 같이 적어둘게요`
- 데이터 항목: 주차장(이름), 주차 시각, GPS 좌표(자동 저장)

### ④-2 층·구역 저장 완료 (`04_주차_기록 완료`)
"'지하 2층 C구역' 한마디 → 위치에 함께 저장 후 폰으로 전송 (대답 없으면 GPS 위치만 저장)"

- 상태 카드 동일
- 체크 아이콘, `지하 2층 C구역`, `위치와 함께 폰으로 보냈어요.`
- 하단: `틀렸다면 다시 말해주세요.` (층/구역 정정 가능)
- 데이터 항목: 층·구역 메모(자유 텍스트, 선택), 폰 전송 여부/시각

### ⑤ 다음 시동 주차 요약 (`05_주차_요약`)
음성: "주차 1시간 40분, 2시간까지 무료예요"

- 무료 주차 시간 카드: `무료 주차 시간` / `20분 남았어요` / 진행 막대 / `1시간 40분 경과` · `2시간 무료`
- 빠른 목적지: `어디로 갈까요?` — `집 32분 · 24.1km`, `회사 18분 · 9.8km` (+ 각 항목 또는 하단 `안내 시작` 버튼)
- 데이터 항목: 주차 시작 시각, 경과 시간, 주차장의 무료 시간, 남은 무료 시간, 사용자 저장 장소(이름, 좌표),
  각 장소까지 소요 시간/거리(내비 계산)

## 화면에서 도출한 엔티티 후보 (해석)

| 후보 | 근거 화면 | 주요 속성 |
|---|---|---|
| 주차장 | ①②③④⑤ | 이름, 좌표, 실내/실외, 입구 안내, 무료 시간(분), 요금(단위 분, 단위 금액), 총 면수 |
| 주차장 혼잡 예측 | ① | 주차장, 대상 시각(30분 슬롯), 예측 만차율(%) |
| 도착 세션(도착 모드) | ①②③ | 사용자, 목적지명/좌표, 목적지 주차장, 예상 도착 시각, 상태, 선택한 경유 주차장 |
| 주차 추천 | ② | 세션, 주차장, 역할(추천/목적지), 거리, 사유 |
| 주차 기록 | ④⑤ | 사용자, 주차장(선택), 좌표, 주차 시각, 층·구역 메모, 폰 전송 시각, 출차 시각 |
| 저장 장소 | ⑤ | 사용자, 이름(집/회사), 좌표 |
| 사용자/기기 | ④ "폰으로 보냈어요" | 외부 인증 subject, 폰 FCM 토큰 |

## 화면에 없는 것 (추측 금지 영역)

- 로그인/회원가입, 결제, 리뷰, 주차장 관리자 기능 화면은 없다.
- 소요 시간/거리(18분 · 12.4km 등)는 내비 계산값으로 보이며 서버 저장 근거는 없다.
- 만차율 예측 알고리즘의 입력 데이터(실시간 점유 등)는 화면에 나오지 않는다.
